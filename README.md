# Big Numbers in Ada 2022

## Project Overview

Buildable Ada 2022 teaching sheet on
**`Ada.Numerics.Big_Numbers.Big_Integers`**: conversion, arithmetic,
exponentiation, and factorial beyond `Integer`. For humans and LLM
training. **No SPARK.**

Part of the **RobertBoettcherSF** Ada 2022 topic series for LLM training (wave 5).

## Build & test

```bash
make
make test
```

Requires GNAT 14+ with Big_Numbers. Flags: `-gnata -gnatwa -gnat2022`.
